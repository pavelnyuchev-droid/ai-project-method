# Экспресс-диагностика зрелости клиента

Своя анкета по мотивам модели зрелости AI PDLC (Сбер, СберТех — материалы для некоммерческого использования со ссылкой; бренд Сбера не используем)
и опросников МИФИ (табл. 7) и ODM3 Сколково. В каждом направлении два вопроса — «классика» и «ИИ»; уровень направления — минимум из двух;
клиенту показываем **профиль из 8 столбиков**, а не одну цифру. Ответы L2 и выше подтверждаются на интервью: «покажите».

Уровни: 0 нет · 1 стихийно · 2 повторяемо (правила есть) · 3 управляемо (метрики, интеграция) · 4 оптимизируется по данным · 5 само адаптируется.

| Направление | Классика (пример уровней 1 / 3 / 5) | ИИ (пример уровней 1 / 3 / 5) |
|---|---|---|
| 1. Управление и стратегия | решения «по ощущению» / 3–5 показателей еженедельно / прогнозы и сценарии | личные подписки на ИИ / бюджет на ИИ, эффект против базы / ИИ предлагает изменения в рамках политик |
| 2. Процессы и регламенты | в головах / описаны в BPMN, замерены, есть владельцы / перестраиваются под изменения | ИИ помогает отдельным людям / ИИ-шаги встроены с проверкой / агенты ведут процесс, человек на исключениях |
| 3. Учёт и данные | таблицы у разных людей / справочники, обмены, проверка качества / данные — управляемый актив | ИИ «читает» выгрузки вручную / ИИ интегрирован с 1С через n8n / ИИ сам поддерживает качество данных |
| 4. Контроль качества результата | «на глаз» / доля ошибок и возвратов меряется / предиктивный контроль | выход ИИ не проверяется / тестовый набор и прогон после правок / ИИ-ревьюер с доказанным согласием |
| 5. Безопасность и ПД | пароли у всех / согласия, уведомления, журнал доступа / непрерывный контроль | ПД в публичных чат-ботах / ПД заменены ИД, в ИИ не уходят / тесты на утечки и инъекции |
| 6. Клиенты и продажи | заявки теряются / воронка и конверсия меряются / персонализация | ИИ пишет тексты / ИИ квалифицирует лиды, есть «к человеку» / ИИ ведёт кампании в рамках бюджета |
| 7. Эксплуатация и поддержка | «чинит тот, кто заметил» / мониторинг, сроки реакции / самовосстановление | нет / ИИ-бот первой линии с эскалацией / авторемедиация известных сбоев |
| 8. ИТ и компетенции | случайные инструменты / архитектура описана / ИТ-стратегия связана с целями | личные подписки / единая точка вызова моделей, учёт затрат / библиотека шаблонов и реестр ИИ-шагов |

Порядок: анкета 15 минут → черновик профиля → интервью 60 минут → профиль и 1–2 самых слабых направления → целевой уровень на 6–12 месяцев → инициативы в ПЛАН.
