# Источники

Входящее как есть: стенограммы, записи встреч, письма, документы заказчика, выгрузки, скачанные материалы.

- **Нейросеть только читает:** не правит, не переименовывает, не удаляет.
- Имя файла: `Что_ГГГГ-ММ-ДД.расширение`, например `Встреча-с-заказчиком_2026-09-12.txt`.
- Резюме каждого источника — в `_резюме/` под тем же именем, с расширением `.md`.
- Пароли, ключи и токены сюда не класть.
