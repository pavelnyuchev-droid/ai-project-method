# Устав проекта

S — только строки, отмеченные (S). M/L — все. Для заказчика — `.docx` по правилам оформления команды; в `ПЛАН.md` — короткий блок и ссылка.

```
## Устав
- Цель (S): <одна фраза: какой результат и для кого>
- Границы — в охвате (S): <…>
- Границы — вне охвата, не трогаем (S): <…>
- Критерий готовности (S): <как поймём, что сделано>
- Обоснование: <какая боль и сколько она стоит>
- Ожидаемые выгоды (измеримо): <часы, ошибки, деньги, скорость — против замера «до»>
- Гипотеза эффекта (L): <метрика: база → цель за N дней; что делаем, если не подтвердится>
- Владелец эффекта у заказчика: <роль>
- ЛПР (утверждает ТЗ и приёмку): <роль>; кто даёт данные: <роли>
- Полномочия исполнителя: <до какого порога меняем без согласования: сроки ±N дней, часы ±N %>
- Отказы: <что заказчик просил, а мы не делаем — дата>
- Этапы и сроки: <этапы с вехами в совершённом виде>
- Как работаем с заказчиком: <каналы, срок ответа, как подтверждается «принято»>

## Допущения
| № | Что приняли без проверки | Как проверим | Статус |
|---|---|---|---|
| Д-1 | | | открыто / подтверждено / опровергнуто |
```
