# Решение по ПД в проекте

Каждый вопрос о персональных данных в проекте — по этому формату, по текущей ситуации проекта. Вопрос Павлу — один, с вариантами и рекомендацией.
Решение — сразу в `РЕШЕНИЯ.md` проекта с причиной.

```
### Вопрос по ПД: <шаг процесса / ситуация>
Ситуация: <что происходит сейчас, какие ПД, где, кто видит; есть ли ИИ на шаге>

А. По методике (базовое положение методики): <что требуется, цена в часах и деньгах, что меняется для заказчика>
Б. Оптимизация процесса: <как перестроить, чтобы ПД не нужны или не попадали к ИИ —
   не собирать / перенести шаг к человеку или коду / шаблон с полями и подстановка в n8n, SQL, 1С без ИИ>; цена; что выигрываем
В. Обоснованное исключение (если нужно): <что именно, почему, какие меры взамен, кто отвечает> — только решением Павла

Рекомендация: <вариант> — <почему; цена>
Решение Павла: <вариант>, дата → Р-xx проекта
```
